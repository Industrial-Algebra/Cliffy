We are pleased to announce **Cliffy v0.4.0**, now on
[crates.io](https://crates.io/crates/cliffy-core) (four crates) and
[npm](https://www.npmjs.com/package/@industrialalgebra/cliffy-core)
(two packages, under the new `@industrialalgebra` org).

Cliffy is geometric state management and distributed synchronization for any
UI framework: classical FRP semantics (`Behavior`/`Event`, in Conal Elliott's
original sense), a Rust/WASM core, and the claim that distributed systems
problems become geometric algebra problems. 0.4.0 is the release where we made
that claim *honest* — by deleting the code that wasn't.

## The salvage: killing an unsound CRDT

The previous distributed layer made a seductive mistake: it used geometric
operations *as the merge*. Geometric means, magnitude-dominance joins — elegant
on a whiteboard, but none of them are semilattice joins over multivectors.
The system's own probe suite caught the failure modes: `join(+1, −1)`
evaluated to `cosh(1)` instead of converging, opposing operations could
annihilate data, and op-id collisions corrupted ordering.

A CRDT that cannot guarantee convergence is not a CRDT. So 0.4.0 removes
`GeometricCRDT`, `GA3Lattice`, and the consensus module built on them, and
replaces the floor with two pieces:

- **`ObservationSet`** — a grow-only set of observations keyed by
  `(participant, sequence)`. Merge is set union: associative, commutative,
  idempotent. Convergence is trivial by construction and cannot annihilate
  data.
- **Deterministic geometric projections** — scalar means, componentwise
  vector means, and rotor consensus via the Markley eigen-mean, computed with
  an in-house Jacobi eigensolve (no external LAPACK dependency, fully
  deterministic). Every node projects the same converged set with the same
  pure function, so every node computes the same value.

Our shorthand for the design: **the merge is boring; the render is
geometric.** Consensus quality is now a math problem (which projection?)
rather than a distributed-systems problem (does the merge converge?).

All six value-oracle probes that documented the old system's failures now pass
against the new one. The same surface is exposed over WASM as
`ObservationSet.observeRotor` / `rotorConsensus` in
`@industrialalgebra/cliffy-core`, and the
[crdt-playground example](https://github.com/Industrial-Algebra/Cliffy/tree/main/examples/crdt-playground)
exposes each projection as an interactive probe panel.

## Ecosystem changes

- **npm org migration**: `@cliffy-ga` is retired. The packages are now
  [`@industrialalgebra/cliffy-core`](https://www.npmjs.com/package/@industrialalgebra/cliffy-core)
  (WASM) and
  [`@industrialalgebra/cliffy-tsukoshi`](https://www.npmjs.com/package/@industrialalgebra/cliffy-tsukoshi)
  (pure TypeScript, zero dependencies, now with a React component library).
  The schism is deliberate — no 0.3.x line will be published under the new
  org.
- **OIDC trusted publishing** for npm: releases authenticate via GitHub's
  OIDC environment with signed provenance attestations. No long-lived npm
  tokens exist to expire or leak.
- **Toolchain modernization**: nightly-pinned dual-lane CI (pinned nightly +
  stable), `nextest`, workspace-wide pedantic/nursery clippy with panic
  denials (~526 findings resolved), a Nix flake devShell, TypeScript 7 with a
  typecheck gate that actually runs, and Apache-2.0 licensing with SPDX
  headers throughout.
- **cliffy-alive** (living UI / cellular automata) lands in the workspace as
  explicitly gated, highly experimental — unpublished and out of scope for
  semver commitments.

## What's next

Phase 2 rebuilds richer consensus on the sound floor: the Knopper U2 encoding
contract, and Schubert-gated observations (GrantRef semantics) for
capability-scoped collaboration. See the
[roadmap](https://github.com/Industrial-Algebra/Cliffy/blob/main/ROADMAP.md)
and the full
[changelog](https://github.com/Industrial-Algebra/Cliffy/blob/main/CHANGELOG.md).

```bash
npm install @industrialalgebra/cliffy-core       # WASM + Algebraic TSX
npm install @industrialalgebra/cliffy-tsukoshi   # pure TypeScript
cargo add cliffy-core                            # Rust FRP core
```
